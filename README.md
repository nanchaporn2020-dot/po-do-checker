# PO vs DO Checker — คู่มือ Deploy (ไม่ต้องใช้เทอร์มินัลเลย)

ทำตามขั้นตอนนี้ทั้งหมดผ่านเว็บเบราว์เซอร์ได้เลย ไม่ต้องพิมพ์คำสั่งใดๆ

## ขั้นตอนที่ 1: สร้าง GitHub Repository

1. ไปที่ https://github.com แล้วสมัครสมาชิก (ถ้ายังไม่มีบัญชี)
2. กดปุ่ม **"New"** (สีเขียว) เพื่อสร้าง repository ใหม่
3. ตั้งชื่อ repo เช่น `po-do-checker` เลือก **Private** (ถ้าไม่อยากให้คนอื่นเห็นโค้ด) หรือ Public ก็ได้ (โค้ดไม่มีข้อมูลลูกค้าอยู่ในนั้น)
4. กด **"Create repository"**

## ขั้นตอนที่ 2: อัปโหลดไฟล์ 3 ไฟล์นี้เข้า Repo (ลากวางได้เลย)

ในหน้า repo ที่สร้างเสร็จ:

1. กด **"Add file" → "Upload files"**
2. ลากไฟล์ทั้ง 3 นี้เข้าไป:
   - `app.py`
   - `requirements.txt`
   - `README.md` (ไฟล์นี้ ไม่จำเป็นต้องอัปโหลดก็ได้)
3. กด **"Commit changes"** ด้านล่าง

## ขั้นตอนที่ 3: Deploy บน Streamlit Community Cloud (ฟรี)

1. ไปที่ https://share.streamlit.io แล้วกด **"Sign in"** ด้วยบัญชี GitHub เดียวกับข้อ 1
2. กด **"Create app"** หรือ **"New app"**
3. เลือก:
   - **Repository**: เลือก repo ที่เพิ่งสร้าง (`po-do-checker`)
   - **Branch**: `main`
   - **Main file path**: `app.py`
4. **ก่อนกด Deploy** ให้กด **"Advanced settings"** เพื่อตั้งรหัสผ่านก่อน (สำคัญมาก ข้ามข้อนี้ไม่ได้):
   - ในช่อง **Secrets** ให้พิมพ์:
     ```
     app_password = "ตั้งรหัสผ่านที่ต้องการตรงนี้"
     ```
   - เปลี่ยนข้อความในเครื่องหมายคำพูดเป็นรหัสผ่านที่จะแจกให้ทีมใช้
5. กด **"Deploy"** แล้วรอสัก 1-2 นาที

เมื่อเสร็จแล้วจะได้ลิงก์หน้าตาประมาณ `https://po-do-checker-xxxx.streamlit.app` — แจกลิงก์นี้พร้อมรหัสผ่านให้ทีมได้เลย

## ขั้นตอนที่ 4: วิธีแก้โค้ดในอนาคต (ก็ไม่ต้องใช้เทอร์มินัลเช่นกัน)

1. ไปที่หน้า repo บน GitHub → เปิดไฟล์ `app.py`
2. กดไอคอนดินสอ (✏️ Edit) มุมขวาบน
3. แก้โค้ดในหน้าเว็บได้เลย แล้วกด **"Commit changes"**
4. แอปบน Streamlit Cloud จะ **rebuild และอัปเดตอัตโนมัติ** ภายในไม่กี่นาที ไม่ต้อง deploy ใหม่เอง

หรือถ้าอยากให้ช่วยแก้โค้ดในอนาคต ส่งเนื้อไฟล์ `app.py` ปัจจุบันมาให้ดู แล้วบอกจุดที่ต้องการแก้ได้เลยเหมือนที่ผ่านมา

## หมายเหตุเรื่องความเป็นส่วนตัวของข้อมูล

- ไฟล์ PO/DO ที่อัปโหลดจะถูกประมวลผลในหน่วยความจำ (RAM) ของเซิร์ฟเวอร์ชั่วคราวระหว่างใช้งานเซสชันนั้นๆ เท่านั้น แอปนี้ไม่ได้เขียนโค้ดบันทึกไฟล์ลงดิสก์ถาวรที่ใดเลย
- อย่างไรก็ตาม Streamlit Community Cloud เป็นบริการฟรีของบุคคลที่สาม (Streamlit/Snowflake) ข้อมูลจะผ่านเซิร์ฟเวอร์ของเขาระหว่างใช้งาน ถ้าข้อมูลของบริษัทมีความอ่อนไหวสูงมาก (เช่น สัญญาลับ/ราคาต้นทุนที่ต้องเก็บเป็นความลับสุดยอด) แนะนำให้พิจารณาเช่า Server ส่วนตัวของบริษัทแทนในอนาคต — บอกมาได้ ช่วยตั้งค่าให้ได้เช่นกัน
- อย่าลืมตั้งรหัสผ่าน (ขั้นตอนที่ 3 ข้อ 4) ก่อนแจกลิงก์จริงเสมอ ไม่งั้นใครก็เข้าใช้งานได้
